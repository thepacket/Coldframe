# Contributing

**Coldframe doesn't accept pull requests.** They're disabled on the repository,
so this isn't a judgement on any particular patch — none arrive.

This is a personal project built partly to learn the domain, and taking patches
would defeat that. The code is MIT licensed: fork it, change it, ship your own
version. That's genuinely encouraged.

## What is welcome

**Issues.** Especially these:

- The biology is wrong. A locus is mislabelled, a cline is an artefact, an
  interpretation doesn't hold. This is the failure mode I'm least equipped to
  catch on my own and the one I most want to hear about.
- A data source moved, changed format, or went away.
- Something is confusing. Coldframe exists to make genomic data legible to
  people meeting it for the first time, so "I don't understand what I'm looking
  at" is a bug report, not a user error.

**Questions** about the data sources, the joins, or why something is built the
way it is.

No issue template, no process. Just say the thing.
